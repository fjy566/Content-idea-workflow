# ADR 0005: 批量推荐度计算与可选 CUDA 模型评分

## 状态

已采用。

## 背景

采集一轮包含多个数据源时，热点推荐度需要随着新增来源更新。旧实现对每个热点单独查询关联信息；如果本轮没有新增数据，空集合还会被当成“未指定范围”，从而错误地扫描全部热点。已训练的 XGBoost 模型还会在训练后被强制切回 CPU，无法利用用户可用的 CUDA。

## 决策

- `None` 表示显式要求全量刷新，空集合表示本轮没有待刷新热点，二者不能混用。
- 采集函数支持收集本轮触及的热点 ID；调度器在整轮采集结束、暂停或超时时统一刷新一次。
- 规则评分使用一次关联查询加载本批次所有原始信息，并在内存中更新统计指标；偏好关键词只读取一次。
- 如果存在已保存模型，使用一次矩阵预测处理本批热点。CUDA 版 XGBoost 使用设备为 CUDA 的 Booster 和批量 `DMatrix`；GPU 预测失败时自动切换 CPU，并在采集日志中记录设备和耗时。
- 没有模型时不调用 AI、不加载 LLM，只执行批量规则评分。

## 结果

本轮采集不会因为空结果触发全表评分；多个数据源共享一次评分过程。训练页和采集日志能显示模型评分设备，模型训练和日常评分都保留 CPU 回退路径。CUDA 仍是可选能力，平台不把显卡或 CUDA 当作运行硬依赖。
