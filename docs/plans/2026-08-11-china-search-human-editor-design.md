# 中国搜索优先与人性化图文编辑器设计

## 产品判断

用户真正需要的是“找到能用的素材并快速放进文章”，而不是学习 Markdown 或理解图片搜索接口。因此默认路径应当是：输入文章段落/标题 → 用中国读者熟悉的搜索引擎找图 → 先下载到本地素材库 → 用户在正文中选择位置 → 实时预览 → 手动保存。搜索结果不是授权证明，素材卡片必须保留来源链接，并在界面上提示发布前核对版权。

关键词搜图没有适合本地单机直接使用的百度官方关键词搜索开放接口；百度官方图像搜索产品主要是基于用户自建图库的以图搜图，需要 API 鉴权。平台因此采用 360 图片搜索的公开关键词检索接口作为中国搜索源，只接受公开 HTTP(S) 图片地址、限制响应体大小、只保存 JPG/PNG/WebP，并把外部结果当作不可信数据处理。搜索失败会明确提示，不再静默切换外国图片源。

## 交互升级

- 图片搜索源在设置中固定为“360 图片（中国）”，避免外国来源混入中国读者工作流。
- 编辑器提供标题、粗体、斜体、删除线、引用、无序/有序列表、链接、代码、表格、提示块、撤销/重做和分隔线工具栏；按钮会复用当前选区，不要求用户记住 Markdown。
- 编辑区增加字数、段落、标题、图片统计；支持“左右分栏 / 只编辑 / 只预览”切换和 Ctrl/Cmd+B、Ctrl/Cmd+I 快捷键。
- 浏览器本地保存未提交草稿，用户可恢复或清除；服务端在编辑后空闲约 5 秒和每 30 秒检查一次自动保存，不自动调用 AI。
- 素材卡片提供“插入光标处”“按章节插入”“复制 Markdown”，并根据正文标题动态生成插入位置；已插入图片会明确显示状态。点击工具栏或卡片按钮后仍使用最后一次正文光标。

## 数据流与边界

`文章标题/小标题` → 本地关键词启发式 → 360 中国搜索 → URL 校验与图片下载 → `GeneratedImage` 素材记录 → 用户选择位置 → Markdown 正文 → 安全实时预览。

搜图查询只发送标题、指令和小标题等关键词，不发送全文；AI 配图仍严格走用户自己的图片 API。预览关闭原始 HTML，图片只展示本地 `/media` 路径。搜索失败不会阻塞文章生成，素材库支持稍后重试。

## 验收标准

1. 默认搜图请求中国搜索源；查询词包含文章主题和章节上下文，模拟的中国源响应中能够跳过无关、重复、无效和超限图片并保存真实图片响应。
2. 中国源不可用时能明确报告失败，不会静默使用外国图片源。
3. 编辑器工具栏能在选区前后插入正确 Markdown，图片按钮能插入最后一次正文光标，Markdown 小抄可通过原生折叠面板打开，统计随输入变化，预览模式可切换，刷新页面后能恢复本地未保存内容。
4. 现有文章生成、多图插入、文章库、推荐模型、采集和加载提示测试全部通过。
