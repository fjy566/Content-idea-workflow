# Markdown 图文编辑器设计

## 目标

把文章生成、图片素材和正文排版连成一个可控流程：篇幅可自定义；一次生成合理数量且主题不同的配图；生成后的图片真实出现在 Markdown 正文中；用户仍可精确调整插入位置。

## 产品决策

- 目标篇幅使用 300–10000 字数字输入，并提供 800、1200、1800、3000 快捷值。
- 配图数量支持自动或 1–6 张。自动数量按目标篇幅计算：800 字以内 1 张、1400 字以内 2 张、2200 字以内 3 张、更长 4 张。
- 默认不配图。只有用户选择搜图或 AI 配图后才执行；AI 模式明确说明一张图对应一次图片 API 调用。
- 搜图不额外调用 LLM。搜索词来自用户说明、文章标题和 Markdown 小标题；同一批次排除重复来源。
- 成功得到的图片会按正文段落均匀插入 Markdown。部分图片失败时保留文章和成功图片，并展示实际完成数量。
- 编辑页把所有图片作为素材卡展示。用户可在文本光标位置一键插入，也可通过服务器端操作插入开头、第一段后、中部或结尾。
- 已存在正文里的图片不会重复插入。
- Markdown 预览使用 `markdown-it-py`，关闭原始 HTML，阻止不安全链接协议。

## 数据流

1. 用户选择写作角度、目标篇幅、配图模式和数量。
2. 文本 API 生成 Markdown 文章。
3. 系统从文章结构提取不同图片主题，逐张搜索或生成并保存素材元数据。
4. 成功图片转为 Markdown 图片块并均匀插入正文。
5. 编辑页服务端渲染安全预览；素材卡可继续调整插入位置。

## 验收

- 任意 300–10000 字目标值能传入文章提示词。
- 自动数量和手工数量都受 1–6 张限制。
- 多张搜索结果来源不重复，失败不删除文章。
- 文章正文包含可访问的 `/media/...` Markdown 图片，并在预览中显示为图片。
- `<script>` 等原始 HTML 在预览中不执行。
- 插入到光标和五种预设位置均不会重复插入同一图片。
