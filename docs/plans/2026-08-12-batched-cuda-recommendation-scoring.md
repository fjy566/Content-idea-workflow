# 批量推荐度与 CUDA 加速实现计划

## 目标

降低采集一轮更新推荐度的等待时间，并在用户安装 CUDA 版 XGBoost 且检测到 NVIDIA GPU 时批量使用 GPU 进行模型预测；没有 GPU、模型或 GPU 预测失败时，功能仍可用。

## 已完成

- 修复空集合触发全表评分的问题。
- 将热点关联信息改为批量查询，避免每个热点一次 SQL。
- 将一轮采集涉及的热点 ID 汇总，整轮结束后只刷新一次；暂停和超时也会先保存已采集热点的评分。
- 将逐热点模型预测改为单次矩阵预测。
- CUDA 版 XGBoost 使用批量 `DMatrix` 预测，失败时回退 CPU。
- 在训练指标、推荐模型页面和采集日志中展示实际评分设备、数量和耗时。
- 增加空批次、批量统计、CUDA 批量预测和 CUDA 回退测试。

## 验收标准

- 空采集不执行全表热点评分。
- 一轮多源采集只执行一次批量评分。
- 训练模型存在时，热点模型分一次性预测；GPU 不可用时仍能得到 CPU 结果。
- CUDA 预测错误不会导致采集任务失败，并有可读日志。
- 全量测试通过，README 与实现保持一致。
