# 配图、单轮采集与本地推荐升级计划

## 目标

在不增加隐式大模型调用的前提下，完成文章配图三选一、单轮采集进度与日志、以及可选择 CPU/CUDA 训练的本地推荐系统。

## 产品规则

- 文章生成前由用户明确选择：不配图、从 Wikimedia Commons 搜索并引用、调用已配置的图片 API 生成。
- 图片搜索不调用大模型；搜索图必须保存来源和署名信息。
- 每次采集是有起止状态的一轮任务，每个选中的数据源最多处理一次；同一时间只允许一轮运行。
- 采集只负责抓取和本地评分，绝不自动触发 AI 选题分析。
- AI 选题分析保留为显式按钮，并标明消耗 Token。
- 推荐器使用真实行为反馈；样本不足时拒绝训练，不制造数据。
- 训练页由用户选择自动、CPU 或 CUDA；CUDA 可用时使用启用 CUDA 的 XGBoost，自动模式失败时回退到 sklearn CPU，并在界面展示实际算法和设备。

## 实施步骤

1. 增加采集运行、采集日志和图片版权元数据模型，兼容现有 SQLite。
2. 实现 Wikimedia Commons 搜图、限制大小的安全下载和署名保存。
3. 扩展文章生成表单与文章详情页，接入三种配图模式并保留失败后的文章。
4. 重构采集调度，记录逐源进度、错误和结果；增加进度页及日志清空。
5. 删除采集后的自动 AI 分析，增加防回归测试。
6. 扩充推荐特征，加入 XGBoost CUDA 自动探测、指标展示和 CPU 回退。
7. 运行单元测试、编译检查、真实 Commons 请求、本机 GPU 探测和浏览器验收。

## 验收标准

- 不选择配图时只生成文章；搜索配图时得到真实文件和可点击来源；AI 配图仅在用户选择时调用。
- 管理页能看到当前轮次、百分比、逐源日志与清空按钮，运行完成后不会继续循环。
- 一轮采集的测试中 AI 分析调用次数为零。
- 推荐页展示不少于原有指标的扩展特征、真实反馈样本数、算法、设备和验证指标。
- 所有已有测试与新增测试通过，服务重启后现有数据仍可使用。
