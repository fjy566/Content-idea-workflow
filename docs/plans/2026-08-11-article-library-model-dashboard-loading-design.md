# 文章库、推荐数据看板与耗时操作反馈设计

## 目标

让已经存在的数据真正可发现、可解释、可操作：文章保存后进入统一文章库；推荐模型展示训练数据与效果；生成初稿等耗时操作明确显示进行中状态并防止重复提交。

## 文章库

- 新增 `/articles`，导航栏增加“文章库”。
- 顶部展示全部、草稿、待发布、已发布数量，支持状态筛选和标题/正文搜索。
- 列表展示标题、来源热点、正文摘要、图片数、模型、更新时间和状态。
- 保存文章后显示明确成功提示，并提供返回文章库入口。
- 热点详情页展示该热点最近生成的文章，避免从热点上下文丢失。
- 状态仍使用现有 `draft`、`ready`、`published`，不迁移或伪造数据。

## 推荐数据看板

- 数据概况：热点总数、反馈事件数、有效训练选题数、数据覆盖率。
- 反馈构成：浏览、收藏、不感兴趣、生成、选角、配图、编辑、发布的真实次数和权重。
- 模型效果：训练/验证样本数、MAE、RMSE、R²、朴素基线 MAE、目标值范围和均值。
- 排序结果：模型分数的区间分布、均值/最小/最大、当前高分选题。
- 可解释性：训练后保存并展示特征重要性前十名。
- 训练历史：展示最近训练时间、算法、设备、样本和误差。
- 训练设备：用户可选择自动、CPU 或 CUDA；CUDA 不可用时显示检测原因并禁用选项。
- 训练进度：后台任务持久化排队、数据准备、训练、验证、应用模型分和刷新排序阶段，页面每秒轮询并展示百分比、实际设备和阶段指标。
- 小样本或负 R² 时显示通俗风险提示，不用“已训练”掩盖模型质量不足。

## 生成中反馈

- 所有 AI 选题、文章、配图和模型训练表单使用统一提交状态；模型训练提交后进入可轮询的持久化任务。
- 提交后全页出现可访问的加载层，显示操作名称、预计耗时、已等待秒数和“不要重复点击/关闭页面”。
- 按钮立即变为进行中并禁用，避免重复生成和重复扣费。
- 保留带 `name/value` 的提交按钮值，确保搜图/AI 模式等业务参数不丢失。
- JavaScript 不可用时仍保持普通表单提交能力。

## 验收

- 现有文章无需迁移即可在文章库中按状态找到。
- 保存状态后返回文章详情并显示成功提示，文章库计数同步变化。
- 推荐页呈现真实反馈、覆盖率、分布、重要性、历史和质量说明。
- 点击生成初稿后 100ms 内出现加载层，按钮不可重复点击，服务端仍收到完整表单字段。
